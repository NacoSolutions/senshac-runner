# Mulch CLI

Use the installed `mulch` executable; its provider shorthand is `ml` in some
repository instructions. Run from the owning repository root.

1. Run `mulch prime` before non-obvious work and apply only relevant guidance.
2. Record reusable, verified lessons with
   `mulch record <domain> --type <type> "<lesson>"`.
3. Validate with `mulch validate` before delivery.
4. Keep credentials, temporary tokens, copied logs, and unverified guesses out
   of durable expertise.

Acceptance: relevant expertise was read; a reusable lesson is recorded when
one was learned; `mulch validate` passes.
