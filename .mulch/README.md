# .mulch/

This directory is managed by [mulch](https://github.com/jayminwest/mulch), a structured expertise layer for coding agents.

## Key commands

- `ml init` — initialize this directory
- `ml record` — record a reusable convention, pattern, failure, decision, reference, or guide
- `ml prime` — load project expertise into an agent session
- `ml validate` — validate all records

Expertise is stored as one JSONL file per domain under `expertise/`.
